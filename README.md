# TrackAI / SignalDesk

SignalDesk 是一个原生 macOS 情报台，用来订阅和监控 AI、机器人、科技、投资领域关键人物与机构的公开动态。

## 当前能力

- RSS / Atom 订阅与自动去重
- SEC EDGAR 13F 新申报监控
- 最近两期 13F 逐证券差分：新增、清仓、增持、减持
- 12 位杰出投资者持仓看板：组合占比、估算成本、估算盈亏及证券 1/3/5/10 年 CAGR
- SEC 13F、OpenFIGI 证券映射与 Twelve Data 复权行情逐层补全并缓存
- 内置 11 位 AI / 机器人关键人物预设，可一键导入并自动去重
- 每位人物独立追踪采访、播客、演讲、对话和视频
- App 打开期间每 15 分钟自动刷新
- 观点、动向、持仓三类统一时间线
- 基于关注主题和高影响关键词的 0–100 重要性评分
- 高价值筛选、搜索、收藏、已读状态
- 高价值新事件系统通知
- 全部状态仅保存在本机

## 运行

要求 macOS 14 或更高版本及 Xcode 16+。

开发运行：

```bash
swift run
```

生成可双击的 macOS App：

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/TrackAI.app
```

构建脚本需要钥匙串中存在有效的 `Developer ID Application` 或
`Apple Development` 代码签名身份，也可通过 `TRACKAI_SIGNING_IDENTITY`
显式指定。脚本不会退回临时签名，以免 App 更新后再次触发钥匙串读取授权。

## 数据边界

- RSS 来源的内容与更新频率取决于发布方。
- 13F 是机构季度申报，存在法定披露时滞，不代表实时持仓。
- v0.7.0 新增杰出投资者持仓看板：
  - 持仓和申报价值直接来自 SEC EDGAR，无需 API Key。
  - 13F 不披露真实成交价；“估算成本”先追溯调整拆股，再按约 5 年季度增仓和当期价格加权，低置信表示建仓早于可见历史。
  - “估算盈亏”和 1/3/5/10 年 CAGR 是证券拆股复权价格指标，不含股息，也不是投资者基金的组合收益。
  - 免费 Twelve Data Basic Key 可补全行情；TrackAI 按 8 个标的一批遵守免费额度并缓存。期权、退市、映射失败或历史不足时显示“—”。
  - 初始内置 12 位偏集中型投资者，避免量化机构数千个仓位耗尽免费行情额度。
- v0.7.1 为 SEC EDGAR 请求补充可联系的 User-Agent，修复持仓刷新返回 403。
- v0.4.0 会移除内置人物包的 X 来源，改为长内容媒体检索；手动添加的其他 X 来源不受影响。
- v0.5.1 为每个条目加入由用户点击按钮后生成并缓存的中文 AI 总结：
  - Apple Foundation Models（macOS 26 且系统资格可用时，免费、本机运行）
  - Ollama + `qwen3.5:4b`（免费、本机运行，需自行安装并下载约数 GB 模型）
  - DeepSeek API（可选付费方案，Key 只存储在 macOS 钥匙串）
  - “本机优先”不会自动把正文发送给 DeepSeek；只有明确选择 DeepSeek 才会调用云端
- v0.5.2 修复详情视图复用时，切换条目未及时从未读更新为已读的问题。
- v0.5.3 让侧边栏主题支持点击筛选、再次点击取消，并显示当前选中状态。
- v0.6.0 将主题标准化为“模型与 Agent、机器人与具身智能、算力与芯片、投资与商业”，细粒度关键词继续单独保留；现有本地条目会自动重新分类。
- v0.6.1 改用稳定的 Apple 代码签名身份，避免每次重建后因临时签名变化而重复请求钥匙串读取权限。
- 媒体检索每 6 小时更新，官方频道 Feed 沿用常规刷新周期。
- LinkedIn 等封闭平台仍需要各自的官方 API 凭据，本版不使用易失效且可能违规的网页爬虫。
- 评分只用于信息分流，不构成投资建议。
